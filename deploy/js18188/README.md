## 目录

- `/opt/starlight/releases/<版本>/www`：前端静态资源。
- `/opt/starlight/releases/<版本>/bin`：Linux amd64 可执行文件。
- `/opt/starlight/current`：当前版本软链接。
- `/var/lib/starlight/source`：号码库与服务间密钥，仅服务用户可访问。
- `/var/lib/starlight/backend`：账户库、业务号码库、首次管理员凭证。
- `/etc/nginx/sites-available/js18188.com`：站点代理及 HTTPS 配置。

服务名为 `starlight-source`、`starlight-backend`、`nginx`，设置开机启动及业务进程故障重启。号码源和业务接口只监听 127.0.0.1 的 8081、8082；外部通过 Nginx 访问网站及 `/api/`。
