# 星彩娱乐

Vue 3 + TypeScript 响应式前端、Go 业务后端与独立 Go 定时号码 API。

## 启动

分别开启三个终端：

```sh
cd game-api
go run ./cmd/server
```

```sh
cd backend
go run ./cmd/server
```

```sh
npm install
npm run dev
```

- 前端：`http://localhost:5173/`
- 管理后台：`http://localhost:5173/f7cc4f635d178admin`
- 业务服务：`127.0.0.1:8082`
- 号码 API：`127.0.0.1:8081`

首次管理员用户名默认为 `admin`，随机密码保存在 `backend/data/admin-bootstrap.txt`，也可首次启动时指定 `ADMIN_USERNAME`、`ADMIN_PASSWORD`。登录后可在个人中心修改密码。

## 已实现

- PC / 手机大厅、游戏场次选择、10个场次、每场次100期初始模拟历史、自动定时开奖、历史分页。所有场次整分前10秒封盘、后05秒开奖（15秒封盘窗口）；澳门六合彩每天21:29:50封盘、21:30:05开奖。
- 登录注册、退出、改密、会话持久化、账户停用、角色权限。
- 余额与冻结金额、余额流水、充值和提现申请、管理员审核。新用户可按后台配置获得注册赠送测试余额，设为0关闭；旧本地模拟积分不会作为账户资金。
- 订单由后端校验期号、号码、玩法设置、金额与余额，幂等扣款；两面/常规订单锁定赔率并自动判奖派彩，支持撤销退回。
- 三级邀请分销：用户同时可以有邀请人和下级；佣金按有效投注与下单时保存的三级比例计算，可领取至余额。
- 快捷金额10/20/50/100/200/500元、自定义6档并按用户保存于当前浏览器，支持直接输入精确到分的投注金额；后台设置起投与单笔上限。
- 两面（定位大小单双、总和、龙虎）与常规（定位数字、快3/PC蛋蛋和值），各场次/位置/选项赔率独立设置。新增g8为1–6可重复10个号码，快3切换g8。
- 后台运营概览、用户搜索/分页/停用/调账、玩法启停/单注金额/倍数/封盘时间、三级比例、公告/注册开关、资金审核、订单管理、佣金及操作日志。

当前充值/提现需人工核对外部款项，不自动连接支付通道；两面默认赔率1.960（含本金），数字赔率为可编辑的初始模板；旧版订单与六号单式仍需人工结算。三级佣金默认全部为0，可在后台分别设置。

## 验证

```sh
npm run build
cd backend
go test -race ./...
go vet ./...
```

号码服务测试在 `game-api` 目录执行 `go test -race ./...`。数据库目录不纳入版本管理。生产部署需 HTTPS、持久化数据库目录，并让 `/api` 反向代理保留原始 Host；设置 `COOKIE_SECURE=true`。当前 bbolt 数据库采用单实例部署。

## 六合规则（2026-10-18）

八个六合彩场次按 [完整玩法说明](backend/docs/lhc-rules-20261018.txt) 统一使用规则版本6；场次名称、周期、封盘、号码来源及49选7（6正码＋1特码）保持不变。新增玩法默认赔率1.000，原有对应赔率和开关沿用后台配置。

三中二的中二/中三、二中特的中特/中二可独立配置并随订单锁定；每组只扣一次本金并派一个中奖档位。正肖按前六个正码中生肖出现次数派彩。各玩法49号和局规则以新说明为准，历史订单沿用原快照。新六合彩不再提供旧六号单式入口。
